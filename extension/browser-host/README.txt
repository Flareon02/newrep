Чтобы Esports Monitor мог открывать ссылки в выбранном браузере, один раз запустите PowerShell из этой папки:

PowerShell -ExecutionPolicy Bypass -File .\Install-BrowserHost.ps1 -ExtensionId ВАШ_ID_РАСШИРЕНИЯ

ID показан внутри Esports Monitor: Настройки -> Браузер для ссылок.
После установки перезагрузите расширение.

Если выбран «Текущий браузер», помощник не нужен.
