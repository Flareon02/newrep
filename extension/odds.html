Коэффициенты карт, если известны

Необязательно. Заполняйте оба исхода карты. Если заданы все карты, исход матча можно оставить пустым.

Входная маржа снимается пропорционально. Для неизвестных карт подбирается одинаковая вероятность. Рынки раундов — приближение, их нельзя однозначно восстановить из исхода матча.

Маржа 7,5% = сумма обратных коэффициентов 107,5%. «Макс. коэффициент» ограничивает итоговую цену: например 35 или 300 → 25 при лимите 25. Изменения применяются сразу.

«Авто» оценивает порядок карт по выбору и банам. Если veto уже известно, выберите карты вручную.

Как добавить или обновить данные HLTV

Размер HAR — до 1 ГБ (1024 МБ). Файл читается частями; в базу попадают только извлечённые данные. Для подробного расчёта откройте также историю карт игроков. Сохраните HAR после посещения страниц двух команд и статистики игроков. Для статистики игроков выберите последние 3 месяца. Импорт читает только спортивные данные из ответов HLTV; cookies и заголовки не используются.

Если HLTV ограничивает запросы с сервера, импорт позволяет работать с сохранёнными данными. Список из HAR ограничен посещёнными страницами, это не вся база HLTV.
